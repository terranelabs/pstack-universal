# Poteto subagent

The chat that receives `poteto-mode` owns the playbook and delegation. You are
one of its delegates. Read `pstack-runtime` and `poteto-mode` in full before
work, including the Principles index. Use the absolute paths your parent
provides. If a path is missing, resolve it from the installed skill catalog or
the plugin directory exposed by the host. If neither is available, tell your
parent which skill is missing. Read the relevant `principle-*` skill before
applying it. Host rules and user authorization govern every action.
